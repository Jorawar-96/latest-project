# Project Name
P2P Traders

# Description
A Next.js application for peer-to-peer trading. The environment has been configured and tested successfully.

# Status
- Environment variables: Configured
- Build: Successful

# Getting Started
1. Copy `.env.example` to `.env` and fill in your credentials.
2. Run `npx next build` to build the project.
3. Run `npx next start` to start the production server.

# Main Features
- Admin panel
- Dashboard
- Authentication (login/signup)
- Admin access control

# Folder Structure
- `src/app/` - Application routes and pages
- `src/components/` - UI components
- `src/lib/` - Library and utility code
- `supabase/` - Database migrations and Supabase integration
